# Task 1 time-box

Task 1 has a hard one-hour limit, and its scope is more than an hour's work by design. Hooks log each session's time in `worklog.md`. When the Stop hook asks for a description, give a one-line summary of what this session achieved.

- Keeping to the hour is Zac's call, and so is what gets cut. Don't refuse or stall because the clock is running. Do flag scope that won't fit.
- Build thin, end-to-end vertical slices one at a time. Every cycle has to finish with working software. Arriving at the hour with half-built layers that don't work is the worst outcome.
- When proposing work, put the smallest slice that works first and leave extras to follow.
