## Summary
Task 1 of the brief. Members can already see their latest blood results on the home screen. This item lets them open a chart of each biomarker's history, with values they can inspect, shown against reference ranges. The brief already decides *that* we build it, so it was fast-tracked from raw straight to shaping. Only *how* is open. The time budget is about 20 minutes, and Task 2 (wearable charts) will reuse whatever chart and API pattern this item settles on.
